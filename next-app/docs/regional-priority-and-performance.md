## 화면과 계산

시장분석 → 지역리포트 상단의 지역 영업 우선순위. 현재 조회 범위를 비교하며 시도 선택을 리포트에도 반영한다. 새 점수에는 경쟁매장 밀도를 사용하지 않는다. 기존 상권 지도 점수는 별도 레거시 지표로 그대로 두었다.

- 완료된 전월 기준 인구 전년 동월 대비. 동 구성 변경 시 보류.
- 최근 완료 3개월 신규 인허가와 전년 같은 3개월 비교. 전년 표본 10건 미만이면 보류.
- 기준월 35~24개월 전 개업 코호트의 24개월 생존 추정. 최소 30곳, 반복 인허가 제외, 상호·주소 매칭. 폐업 대조는 적격 업태 필터 밖 폐업도 포함한다. 현재 영업 중 실사를 뜻하지 않는다.
- 36개월 스냅샷 존재, 원본 로드 완료, 인구 비교 가능 여부, 표본, 식별정보 누락을 표시한다. 스냅샷 존재는 원천 수집 완전성을 보증하지 않는다.
- 비교 가능 지역 2곳 이상일 때 인구·신규·생존 백분위를 같은 비중으로 합산. 신뢰도는 가산점이 아니라 산출 요건이다. 동률 백분위는 중간 순위를 사용한다. 매출 예측으로 검증된 모델은 아니다.
- 아래 기존 기획보고서의 최초 관측월 대비 인구 변화 및 12개월 신규와 기간이 다르다. 기존 AI 설명의 고정 '4년' 표현은 '관측기간'으로 정정했다.

전국 비교를 완성하려면 다른 시도의 전년 인구를 추가 수집하고 행정구역 이력을 대조해야 한다. 사용자 관할 밖까지 모든 원본을 모바일로 내려받는 방식으로 전국 순위를 확장하지 않았다.

## 성능 진단

설정 → 앱 속도 진단. 화면 마운트부터 최대 60초, 화면 이동·앱 숨김 시 종료. 최근 30회는 기기에 저장하고 `/api/performance`를 통해 `[miso-performance]` 접두어로 Vercel 운영 로그에 기록한다. 로그 보존기간은 Vercel 설정에 따른다. 별도 DB 테이블은 필요 없다.

- 지도 SDK 준비, 데이터 첫 단계 준비 시간. 전체 데이터·마커 완료나 콜드 스타트 총시간을 뜻하지 않는다.
- 긴 작업 수/50ms 초과 차단시간, 지원되는 경우 최대 이벤트 지연, 오류 횟수. FPS/정식 INP 점수는 아니다.
- iOS/PWA 여부, 모바일 여부만 구분하며 계정·매장·검색어·오류 전문은 수집하지 않는다. 미지원 API는 null로 유지한다.
- 요청은 로그인 및 값/경로 허용목록을 검증하고 임의 속성을 로그에 남기지 않는다. 업로드 실패 시 기기 기록은 남으며 자동 재시도하지 않는다.

## 정리 및 검증

공통 제외 키워드·편의점 패턴·음식점 패턴은 `store-exclusions.ts`로, 기존 상권 점수는 `commercial-score.ts`로 분리했다. 시장분석 전용 시설 제외와 인허가 추출의 차이는 유지한다. 리포트에서 동명 시군구가 타 시도와 섞이는 집계/선택을 수정했다.

검증: `node scripts/check-regional-priority.mjs`, `node scripts/check-mobile-map.mjs`, `npx tsc --noEmit`, 변경 모듈 ESLint, `npx next build --webpack`. 가상 데이터로 실제 우선순위 컴포넌트의 390px 모바일 화면과 보류·동률·설명 펼침을 확인했다. 실제 iPhone의 FPS 실측은 수행하지 않았다.
