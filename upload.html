데이터 관리

지점 데이터를 확인하고 관리합니다. 담당자·거래처는 직접 편집, 인허가·방문일지는 엑셀 업로드로 교체합니다.

1 — 업로드할 데이터 유형
📋 담당자 등록 안내

인허가 알림 이메일 및 앱 담당자 필터가 정상 작동하려면 아래 절차대로 담당자를 등록해주세요.

① 엑셀 작성 방법

컬럼 입력 예시 설명
시도경기도도/광역시 전체 명칭
시군구포천시담당 지역 시/군/구 명칭
담당자홍길동담당자 실명 (방문일지 작성자명과 동일하게)
이메일hong@example.com인허가 알림 수신 이메일 (필수)

② 지점장 등록 방안

지점장님은 시군구 컬럼에 지점장이라고 입력하세요.

③ 업로드 절차

템플릿 다운로드 → 작성 → 드래그앤드롭 업로드 → 확인 버튼
기존 담당자를 수정하려면 DB 다운로드 또는 현재 DB 현황에서 각 셀을 클릭하여 변경 가능합니다.

📋 방문일지 업로드 안내

작성일 + 작성자 + 방문처(거래처) 조합이 기존과 동일하면 건너뛰고 신규 행만 추가됩니다. 매주 방문일지 누적분을 그대로 업로드하면 됩니다.

① 필수 컬럼

컬럼 입력 예시 설명
NO1업로드 시 무시됨 — 임의 번호 입력 가능
작성일2026-03-10YYYY-MM-DD 형식 (필수)
작성자홍길동담당자 이름 (담당자관리와 동일하게)
방문처(거래처)행복카페거래처 상호명 (필수)
내용원장님 면담...방문 내용 (AI 브리핑 품질에 영향)

② 자주 발생하는 오류

  • 날짜가 텍스트 형식인 경우 → 셀 서식을 날짜(YYYY-MM-DD)로 변경
  • 작성자 이름이 담당자관리와 다른 경우 → AI 브리핑에서 본인 거래처를 인식 못함
  • 동일한 작성일 + 작성자 + 방문처(거래처) 조합이 이미 DB에 있으면 업로드가 건너뜀 (정상 동작)

💡 템플릿 컬럼에 맞춰 방문일지의 동일한 컬럼 내용을 채워 업로드하세요. NO 컬럼은 업로드 시 무시됩니다.
