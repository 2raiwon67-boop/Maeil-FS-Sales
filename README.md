# 경기북부 FS 인허가 대시보드

이 프로젝트는 경기북부 FS팀의 인허가 현황을 시각화하는 대시보드입니다.

## 🚀 다른 컴퓨터에서 시작하기

### 1. 다운로드 (Clone)
```bash
git clone https://github.com/2raiwon67-boop/Maeil-FS-Sales.git
cd Maeil-FS-Sales
```

### 2. 실행 (로컬 서버)
`start_server.bat` 파일을 더블클릭하면 로컬 서버가 실행됩니다.
- 주소: http://localhost:8000
- **Node.js**가 설치되어 있어야 합니다. (없다면 설치 필요)

### 3. GitHub Pages (웹 버전)
설치 없이 바로 확인하려면 아래 링크로 접속하세요:
👉 https://2raiwon67-boop.github.io/Maeil-FS-Sales/

## 🛠️ 주요 파일
- `index.html`: 대시보드 메인 파일
- `server.js`: 로컬 테스트용 서버 파일
- `start_server.bat`: 서버 실행 스크립트

## ⚠️ 주의사항
- 카카오맵이 안 보인다면 `http://localhost:8000` 도메인이 카카오 개발자 사이트에 등록되어 있는지 확인하세요.
